ภาพรวม

สรุปสถานะการผลิต/สต็อก วันนี้
ล็อตสินค้าใกล้หมดอายุ
สินค้าLotคงเหลือวันหมดอายุเหลือ

รับเข้าคลัง

บันทึกรับวัตถุดิบและแพ็คเกจจิ้งเข้าคลัง
เลขที่รับหมวดหมู่รายการจำนวนซัพพลายเออร์Lotวันเก็บเกี่ยววันที่รับจัดการ

สต็อกวัตถุดิบ

ยอดคงเหลือวัตถุดิบสมุนไพรปัจจุบัน
รหัสวัตถุดิบคงเหลือหน่วยขั้นต่ำสถานะ

สต็อกแพ็คเกจจิ้ง

ยอดคงเหลือวัสดุบรรจุภัณฑ์ปัจจุบัน
รหัสแพ็คเกจจิ้งคงเหลือหน่วยขั้นต่ำสถานะ

แผนผลิต / คำสั่งผลิต (MO)

วางแผนผลิตลูกประคบตามคำสั่งซื้อหรือสต็อกล่วงหน้า
MOสินค้าจำนวนแผนวันที่ผลิตกะอ้างอิง COสถานะจัดการ

เบิกวัตถุดิบเข้าสายผลิต

เลือก MO ที่ยังไม่เบิก ระบบคำนวณวัตถุดิบตามสูตรให้อัตโนมัติ
MOสินค้าจำนวนแผนวันที่ผลิตจัดการ
ประวัติการเบิกวัตถุดิบ
เลขที่เบิกMOวัตถุดิบสำหรับผลิตตามสูตรScrapเบิกจริงวันที่เบิก

บันทึกผลิต

บันทึกผลการผลิตจริง ออก Lot / วันผลิต / วันหมดอายุ
MOสินค้าจำนวนแผนวันที่ผลิตจัดการ
ประวัติการบันทึกผลิต
เลขที่ผลิตสินค้าจำนวนที่ผลิตได้Lotวันผลิตวันหมดอายุจัดการ

รับสินค้าสำเร็จรูปเข้าคลัง

รับลูกประคบที่บันทึกผลิตแล้วเข้าคลัง FG
เลขที่ผลิตสินค้าLotจำนวนผลิตได้วันหมดอายุจัดการ
ประวัติการรับเข้าคลัง
เลขที่รับสินค้าLotจำนวนวันที่รับ

สต็อกสินค้าสำเร็จรูป

ยอดคงเหลือแยกตาม Lot / วันหมดอายุ
สินค้าLotคงเหลือวันผลิตวันหมดอายุสถานะ

คำสั่งซื้อลูกค้า

รับคำสั่งซื้อจากลูกค้า/ฝ่ายขาย
เลขที่ COลูกค้าสินค้าสั่งซื้อเบิกไปแล้ววันที่ต้องการสถานะจัดการ

เบิก FG / จัดส่ง

เบิกสินค้าตาม CO (FEFO ตามวันหมดอายุจริง) และติดตามสถานะจัดส่ง
คำสั่งซื้อที่ยังค้างส่ง
เลขที่ COลูกค้าสินค้าค้างส่งสถานะจัดการ
รายการจัดส่ง
เลขที่จัดส่งCOสินค้า/Lotจำนวนสถานะจัดการ

Stock Card

คำขอสมัครใช้งาน

คำขอรหัสจากหน้า login — สร้างบัญชีที่ Supabase แล้วกด "สร้างแล้ว"
สร้างบัญชีที่ Supabase → Authentication → Users → Add user → Create new user ด้วย Email และ Password ตามคอลัมน์ในตาราง และติ๊ก Auto Confirm User เสมอ — พนักงาน login ด้วย Username ได้เลย (ไม่ต้องพิมพ์ @blminternal.com) · ผู้ใช้ใหม่จะเป็นระดับ "พนักงาน" อัตโนมัติ

วิธีเพิ่มผู้ใช้ใหม่ (ให้น้องในทีม)
  1. เปิด Supabase → Authentication → Users → กด Add user → Create new user
  2. กรอกอีเมล + รหัสผ่าน และติ๊ก Auto Confirm User (ไม่งั้นจะ login ไม่ได้จนกว่าจะยืนยันอีเมล) — ถ้าน้องกด "ขอรหัส" มาแล้ว ดู Email/Password ที่ต้องใช้ได้ในหน้า คำขอสมัครใช้งาน
  3. กลับมาหน้านี้กด รีเฟรช — ผู้ใช้ใหม่จะขึ้นเป็น พนักงาน อัตโนมัติ แล้วค่อยปรับสิทธิ์/ตั้งชื่อแสดงผล
  4. แจ้งอีเมล + รหัสผ่านให้น้องเอง (ระบบไม่ส่งอีเมลให้)
